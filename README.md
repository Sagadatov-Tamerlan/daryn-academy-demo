# Daryn Academy Demo

Демонстрационный одностраничный сайт для детской образовательной академии «Дарын» в Астане.

## Локальный запуск

Проект не требует сборки или зависимостей. Откройте `index.html` в браузере либо запустите любой статический HTTP-сервер.

## Структура

- `index.html` — семантическая разметка страницы
- `styles.css` — mobile-first адаптивный дизайн и анимации
- `script.js` — мобильное меню, форма и интерактивные состояния
- `vercel.json` — конфигурация статического деплоя

Это демонстрационный макет. Форма не отправляет данные, а телефон и реальные отзывы должны быть добавлены после согласования.
